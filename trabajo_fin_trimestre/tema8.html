El modelo de caja

En CSS, cada elemento se representa como una caja. Sus partes son el contenido, el relleno, el borde y el margen.

  • Contenido: texto, imagen u otro elemento.
  • Padding: espacio entre el contenido y el borde.
  • Border: borde que rodea el contenido y el relleno.
  • Margin: espacio exterior que separa las cajas.
.caja {
    padding: 20px;
    border: 2px solid green;
    margin: 10px;
}

Otras propiedades

display define cómo se muestra un elemento. overflow controla el contenido que no cabe dentro de una caja. También se pueden cambiar bordes, fondos y fuentes.
