1

Introducción y contextualización práctica

CSS está en continua evolución y el número de propiedades que se pueden usar en las reglas CSS es cada vez más elevado, lo cual permite un mayor control del aspecto visual de la página web. Conocer estas propiedades, así como saber cómo se aplican a los elementos HTML, es importante.

Existen propiedades asociadas a las tablas, a las imágenes, a los textos, etc. Algunas de ellas son generales y otras son específicas de los elementos HTML, las cuales nos van a posibilitar controlar no solo su aspecto visual, sino también su disposición dentro de la página web.

La agencia de viajes Sol y Mar le solicita a Alberto que incluya en su web información sobre los itinerarios de los viajes.

Propiedades CSS

Las propiedades CSS estarán condicionadas al elemento HTML al que queramos aplicar un estilo. Las propiedades de las que se dispone en las versiones CSS 2.1 y CSS3 son numerosas. En este apartado vamos a nombrar las más importantes.

2.1. Propiedades del texto

Con estas propiedades podremos cambiar características del texto que se incluya en la web. Algunas de ellas son:

Tabla 1. Propiedades del texto
PropiedadSignificadoValores
text-alignAlinear el texto.left, right, center, justify
colorIndica el color del texto.Valor RGB, HEX o nombre.
background-colorIndica el color de fondo.Valor RGB, HEX o nombre.
text-decorationEfectos de tachado, subrayado, etc.none, underline, overline, etc.
letter-spacingEspacio entre caracteres.normal o una longitud.
word-spacingEspacio entre palabras.normal o una longitud.
text-transformMayúsculas o minúsculas.uppercase, lowercase
line-heightEspacio entre líneas.Longitud o porcentaje.

2.1.1. Ejemplo de propiedades del texto

En el siguiente ejemplo se aplican algunas de estas propiedades:

<style>
    #p1 {
        text-align: right;
        color: rgb(255, 0, 0);
        text-decoration: underline;
        word-spacing: 20px;
    }
    #p2 {
        text-align: left;
        color: blue;
        letter-spacing: 10px;
        line-height: 5rem;
    }
    #p3 {
        text-align: center;
        background-color: #00FF00;
        letter-spacing: 5px;
        text-transform: uppercase;
    }
</style>

5

Pseudoclases y pseudoelementos

Con las pseudoclases y los pseudoelementos podremos acceder a ciertas partes de los elementos HTML sin tener que crear nuevas clases o identificadores. Las pseudoclases se indican con dos puntos (:) y los pseudoelementos con dos puntos dobles (::).

5.1. Pseudoclases para acceder a hijos o hermanos

Con estas pseudoclases accederemos a elementos contiguos al elemento padre.

Tabla 4. Pseudoclases para acceder a hijos
PseudoclaseSignificado
:first-childPrimer hijo.
:last-childÚltimo hijo.
:nth-child(n)Enésimo hijo. Se pueden indicar valores como odd y even para los hijos impares o pares.

5.2. Pseudoclases de estado

Dependiendo de su estado, se van a poder asociar características a ciertos elementos HTML. Es muy frecuente usarlas en etiquetas de enlace <a>, pero se pueden aplicar a otros elementos.

Tabla 5. Pseudoclases de estado
PseudoclaseSignificado
:linkEl enlace aún no ha sido visitado.
:visitedEl usuario ha visitado el enlace.
:hoverEl cursor pasa por encima.
:activeSe activa cuando el usuario pulsa en el elemento.
:focusEl elemento recibe el foco, por ejemplo, al seleccionarlo con la tecla Tab.

5.3. Pseudoelementos

Con los pseudoelementos podremos acceder a partes concretas del elemento HTML para complementarlas o modificarlas.

Tabla 6. Pseudoelementos
PseudoelementoSignificado
::first-linePrimera línea de texto.
::first-letterPrimera letra del texto.
::beforeInserta contenido antes del texto.
::afterInserta contenido después del texto.

Con los pseudoelementos ::before y ::after podremos añadir contenido con la propiedad content. En el siguiente ejemplo se muestra cómo usar esta propiedad.

5.4. Ejemplo de pseudoclases y pseudoelementos

En este ejemplo se muestra cómo se aplican pseudoclases y pseudoelementos a los elementos de la página web:

<style>
    ul li:first-child { color: red; }
    ul li:last-child { color: green; }
    ul li:nth-child(2) { color: blue; }
    a:link { color: blue; }
    a:visited { color: red; }
    a:hover { background-color: yellow; }
    li::first-letter { text-transform: uppercase; }
    p::after { content: " - Esto es un párrafo"; }
</style>
<p>PAÍSES</p>
<ul>
    <li>españa</li>
    <li>bélgica</li>
    <li>francia</li>
</ul>
<p>MENÚ</p>
<a href="#inicio">Inicio</a>
<a href="#servicios">Servicios</a>
<a href="#contacto">Contacto</a>

Código 4. Uso de pseudoclases y pseudoelementos.

Con :first-child se aplica el color rojo al primer elemento de la lista; con :last-child, el verde al último; y con :nth-child(2), el azul al segundo. A este último caso podríamos haberle indicado even y, como el 2 es par, tendría el mismo efecto.

En el ejemplo, cuando el enlace aún no ha sido visitado (:link) se muestra azul; cuando se ha visitado (:visited), rojo; y cuando se pasa el cursor por encima (:hover), se muestra amarillo el color de fondo.

Por último, se ponen en mayúsculas las iniciales de los países (::first-letter) y se añade después de todos los párrafos (::after) el contenido «- Esto es un párrafo».

Modelo de cajas

El modelo de cajas es uno de los aspectos más importantes a la hora de diseñar y ubicar elementos en una página web. Este modelo se basa en que todos los elementos de una página HTML son considerados cajas rectangulares. De esta manera, cuando insertamos un párrafo, un div, una imagen o una tabla, se crean cajas con las características que se muestran en la siguiente figura:

En el modelo podemos observar:

  • Contenido (content): se trata del contenido propiamente dicho y puede ser texto, una imagen, una tabla, etc.
  • Relleno (padding): espacio existente entre el contenido y el borde. Es transparente.
  • Borde (border): línea que encierra tanto el contenido como el relleno.
  • Imagen de fondo (background-image).
  • Color de fondo (background-color).
  • Margen (margin): espacio que va a existir con el resto de cajas contiguas al elemento HTML. Es transparente.

El orden de las capas es importante. Si se indican tanto la imagen de fondo como el color de fondo, la imagen tendrá prioridad porque está por delante en la jerarquía. Si la imagen consta de partes transparentes, permitirá ver el color de fondo.

Para el relleno, el borde y el margen se pueden definir valores diferentes para los lados superior, inferior, izquierdo y derecho.

7.1. Propiedades asociadas a las cajas

Las propiedades que nos van a permitir modificar el aspecto y el comportamiento de la caja son:

Tabla 8. Propiedades de las cajas
PropiedadSignificadoValores
paddingTamaño del relleno de la caja.Longitud o porcentaje.
marginTamaño del margen de la caja.Longitud, porcentaje o auto.
border-widthAncho del borde.Longitud, thin, etc.
border-colorColor del borde.Color o transparent.
border-styleEstilo del borde.none, hidden, dotted, etc.
background-imageImagen de fondo.url(...)

Para indicar valores independientes a los lados de la caja, simplemente hay que añadir los sufijos -top, -right, -bottom y -left a la propiedad deseada.

En el caso del borde, existe una versión reducida (shorthand) que permite indicar el ancho, el estilo y el color en una misma propiedad:

p { border: 4px solid blue; }

Existen también propiedades asociadas a la imagen de fondo:

  • background-position: indica dónde ubicar la imagen.
  • background-size: indica el tamaño de la imagen.
  • background-repeat: indica si se repite o no la imagen.
  • background-attachment: indica si la imagen permanece fija aunque se haga scroll.

Todos los elementos HTML de una página son cajas, incluido body. Por lo tanto, podemos asociar una imagen de fondo a un div o colocarla como fondo de la página:

<style>
    body {
        background-image: url("raton.png");
        background-repeat: no-repeat;
        background-attachment: fixed;
        background-position: center;
        background-size: 150px 100px;
    }
</style>

7.2. Tamaño de las cajas

A las cajas les podemos dar un tamaño mediante las siguientes propiedades:

Propiedades para definir el tamaño de las cajas
PropiedadSignificadoValores
widthAncho de la caja.auto o tamaño.
max-widthAncho máximo que puede tener la caja.none o tamaño.
min-widthAncho mínimo.0 o tamaño.
heightAltura de la caja.auto o tamaño.
max-heightAltura máxima de la caja.none o tamaño.
min-heightAltura mínima.0 o tamaño.

Cuando se indica un valor auto en alguna propiedad, el navegador se encarga de calcular el tamaño dependiendo del contenido del elemento y del espacio existente en la página web. Con los prefijos max- y min- se puede limitar la medida de las cajas.

Por ejemplo, si la caja tiene un tamaño expresado en porcentaje y modificamos el de la ventana, dicha caja nunca se reducirá o ampliará más allá de los límites indicados:

<style>
    p {
        border: solid 2px blue;
        padding: 10px;
        width: 50%;
        max-width: 300px;
    }
</style>
<p>Este párrafo no va a crecer más de 300px.</p>

El párrafo intentará tener un tamaño del 50 % con respecto al de la ventana, salvo que se amplíe tanto que supere los 300 px. En ese caso, su tamaño se limitará a esos 300 px.

7.3. Propiedades que debemos considerar en el modelo de cajas

Hay ciertas propiedades que afectan a la visualización de las cajas. Cabe destacar las siguientes:

  • box-sizing: permite indicar cómo se va a calcular el ancho y el alto de una caja:
    • content-box: los valores de width y height se refieren al contenido; el relleno y el borde se añaden al tamaño final.
    • border-box: los valores de width y height incluyen el contenido, el relleno y el borde.
  • display: permite modificar el comportamiento de una caja. Algunos valores principales son:
    • none: se oculta el elemento y no ocupa espacio en el diseño.
    • block: se crea la caja como un bloque.
    • inline: la caja se muestra en línea, dentro del flujo del texto.
  • visibility: permite ocultar elementos. A diferencia de display: none, el elemento con visibility: hidden se hace invisible, pero continúa ocupando espacio. Sus valores son visible y hidden.
  • overflow: controla qué debe hacerse cuando el contenido desborda el tamaño de una caja:
    • visible: el contenido se muestra fuera de la caja.
    • hidden: se oculta lo que no cabe.
    • scroll: se generan barras de desplazamiento.
    • auto: el navegador añade barras de desplazamiento si son necesarias.

7.4. Ejemplo de las propiedades de las cajas

Caso práctico 1: «Viajes más frecuentes»

Planteamiento: la agencia de viajes Sol y Mar se pone en contacto de nuevo con WebMalagaDesign y le comenta a Gloria que quiere incluir más contenido en la web.

Nudo: la responsable de la agencia quiere añadir una tabla con los destinos más frecuentes. La tabla debe estar incluida en la parte superior de la web y debe cumplir las siguientes características:

  • Siempre debe ocupar el 50 % del ancho de la página y estar centrada.
  • Tanto el título de la tabla como la cabecera deben tener el tipo de fuente Verdana. El título debe tener las letras más separadas que el texto normal de la página.
  • El tamaño de la fuente de la cabecera debe ser 1,5 veces el tamaño de la fuente normal de la página.
  • Dentro de la tabla, los orígenes y los destinos deben estar alineados a la izquierda, y los precios, a la derecha.
  • Debe haber un espacio entre el contenido y el borde de la celda.
  • Las filas pares tendrán un color y las impares otro. Cuando el cursor se coloque encima de una fila, esta debe cambiar de color.

Caso práctico 2: «Tablero de ajedrez»

Planteamiento: una empresa de juegos tiene un blog dedicado al ajedrez y se pone en contacto con WebMalagaDesign porque necesita el diseño de un tablero de ajedrez en HTML y CSS para poder mostrar jugadas. Por ahora, solo solicitan un borrador de la solución en el que se muestren algunos peones blancos y negros.

Nudo: Alberto habla con Gloria y plantean un código HTML y CSS muy estructurado para que sea fácilmente escalable y así poder incluir nuevas jugadas en un futuro. Para realizarlo, han llegado a las siguientes conclusiones de diseño:

  • El tablero tendrá 8 × 8 celdas.
  • Las cabeceras mostrarán las columnas (letras) y las filas (números) con un formato diferente.
  • Las celdas negras y blancas se indicarán con clases CSS con un color de fondo.
  • Cada celda tiene que estar referenciada con identificadores, por ejemplo, id="A7".
  • Para poner una figura del ajedrez en el tablero, se asociará a la clase de la celda otra clase especial con el nombre de la figura y su color. Por ejemplo, class="blanco peon_blanco".
  • La clase de la figura tendrá una imagen de fondo asociada a una imagen PNG.

Gloria no entiende cómo se puede asociar otra clase si las celdas ya tienen una. Alberto le comenta que a un mismo elemento se le pueden aplicar dos clases; simplemente hay que indicarlas separadas por un espacio en el atributo class.

<td id="A7" class="blanco peon_blanco"></td>
