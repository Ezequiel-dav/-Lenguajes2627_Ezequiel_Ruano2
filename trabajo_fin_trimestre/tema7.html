1

Introducción y contextualización práctica

En los temas anteriores hemos construido el contenido de la página web. Sin embargo, han quedado en un segundo plano temas como la disposición de los elementos, los colores y las fuentes. Ese diseño se realizará con las hojas de estilo y permitirá personalizar un documento web tanto en la pantalla como a la hora de imprimirlo.

Las hojas de estilo han supuesto un avance muy importante en el diseño web, ya que ofrecen un rango de posibilidades muy amplio para conseguir mejoras en los documentos HTML. Inicialmente no se le daba tanta importancia al aspecto. No obstante, desde que la web se democratizó, la presentación ha ganado un papel muy importante en la creación de sitios web.

Alberto quiere dotar de más contenido a la intranet de la empresa y, para ello, quiere tener los CV de todos los trabajadores en formato web. Se pone manos a la obra y le pide a Gloria que le ayude con la plantilla.

2

Introducción a CSS

CSS representa las siglas de Cascading Style Sheets (hojas de estilo en cascada), que podemos definir como el lenguaje que nos permite controlar el aspecto visual de nuestro documento HTML. HTML y CSS se complementan para separar el contenido y su presentación.

Esta división nos aporta numerosas ventajas, puesto que, al ser independientes el contenido y el aspecto visual, para un mismo contenido podremos tener diferentes visualizaciones. Esta característica es fundamental para poder trabajar en distintos dispositivos.

En la siguiente web verás un ejemplo de cómo cambia visualmente un mismo contenido cuando se le aplican diferentes hojas de estilo. Te sorprenderán los cambios.

2.1. Historia de CSS

Al igual que HTML, CSS ha evolucionado a lo largo de estos años, por lo que han aparecido diferentes versiones, cada una de las cuales mejoraba la anterior, incluyendo la corrección de errores y mejoras en su funcionalidad. En el organismo oficial W3C puedes consultar la evolución de este lenguaje.

2.2. CSS y los navegadores

Los navegadores interpretan de manera distinta el CSS. Por ello, es muy importante conocer las posibles limitaciones del navegador para conseguir la máxima compatibilidad. Es posible que con ciertos navegadores tengamos que incluir una sintaxis específica para alcanzar la correcta visualización de la página web.

Chrome, Safari, Firefox y Opera se encuentran entre los navegadores que ofrecen amplia compatibilidad con CSS. El material de referencia destaca el soporte completo de CSS 2.1 y muchas características de CSS3. Conviene comprobar la compatibilidad de las propiedades que se utilicen en los navegadores más populares.

3

Características de CSS

Antes de usar CSS, cuando se quería modificar el aspecto visual de los elementos HTML, se incluían en la propia etiqueta algunos atributos como color, fuente, etc. Hoy en día esta forma de trabajar todavía se permite, pero es una práctica obsoleta, y todo lo relacionado con el aspecto visual debe llevarse a la hoja de estilos.

3.1. Formas de incluir CSS en HTML

Hay tres formas de indicar al documento HTML qué estilo queremos aplicar y cómo:

  • En el propio elemento HTML: se indica el estilo en la propia etiqueta. Este método no es el más adecuado, pues hay que indicar el estilo etiqueta a etiqueta.
  • En el documento HTML: se puede incluir el estilo en la cabecera del documento utilizando la etiqueta <style>.
  • En un fichero externo: es el método que más se utiliza, porque podemos tener los estilos del documento separados en un fichero externo. Se indica en la cabecera con la etiqueta <link>, que tiene los siguientes atributos:
    • rel: relación entre HTML y el fichero externo. En este caso se indica que es una hoja de estilo mediante el valor stylesheet.
    • type: indica el tipo de recurso. En este caso, el valor es text/css.
    • href: dirección URL donde se encuentra el fichero externo. Puede estar en local o ser una dirección de Internet.
<!DOCTYPE html>
<html lang="es">
<head>
    <title>CSS en elemento HTML</title>
    <style>
        h2 { color: green; }
    </style>
    <link rel="stylesheet" type="text/css" href="estilos.css">
</head>
<body>
    <h1 style="color: blue">Estilo en el propio elemento</h1>
    <h2>Estilo en el documento HTML</h2>
    <h3>Estilo con archivo externo</h3>
</body>
</html>

Código 1. Formas de incluir CSS en HTML. En el archivo externo estilos.css se podría incluir la regla h3 { color: red; }.

3.2. Sintaxis de CSS

Tal y como sucedía con los documentos HTML, el fichero CSS es un fichero de texto plano en el que se van incluyendo las reglas propias de CSS. El navegador interpreta este fichero y lo aplica al HTML.

La sintaxis sigue el siguiente patrón:

selector {
    propiedad: valor;
}
  • Selector: es el elemento HTML al cual se le va a aplicar el estilo que indiquemos. Por ejemplo, un párrafo <p>.
  • Propiedad: es la característica que se va a cambiar. Por ejemplo, el color.
  • Valor: es el valor que se le asigna a la propiedad. Por ejemplo, el color rojo.

El fichero CSS puede contener cientos de reglas aplicadas a diferentes elementos HTML. Cuando queramos aplicar más de un estilo a un elemento, debemos separarlos con punto y coma. El material de referencia contabiliza 115 propiedades en CSS 2.1 y 239 en CSS3.

3.3. Comentarios

En CSS también se pueden incluir comentarios, lo cual es altamente recomendable, porque a medida que se van creando reglas, el fichero aumenta de tamaño y es complicado seguir el flujo de reglas que debemos aplicar.

Los comentarios se indican con los caracteres /* para iniciar el comentario y */ para finalizarlo. El navegador ignorará todo lo que se encuentre entre esos caracteres, pero nos servirá para incluir información que contribuirá a una mejor interpretación de cómo se aplican las reglas CSS.

<!DOCTYPE html>
<html lang="es">
<head>
    <style>
        p {
            color: red; /* Indicar el color rojo */
        }
    </style>
</head>
<body>
    <h2>Cabecera</h2>
    <!-- Estos párrafos se muestran en rojo -->
    <p>Hola Mundo!</p>
    <p>Los párrafos tienen aplicado estilo.</p>
    <p>Los comentarios HTML y CSS no se muestran en el navegador.</p>
</body>
</html>

4

Selectores

Gracias a los selectores podremos escoger a qué elemento o grupo de elementos HTML le vamos a aplicar la declaración de la regla CSS. Los selectores se pueden clasificar en los siguientes tipos:

  • Universal: selecciona todos los elementos HTML de la página. Se indica por medio de un asterisco (*).
  • Etiqueta: selecciona todos los elementos HTML que coinciden con la etiqueta indicada.
  • Clase: permite agrupar elementos a los que interese aplicar un cierto estilo. En el elemento HTML se utiliza el atributo class; en las reglas CSS se antepone un punto (.) al nombre de la clase.
  • Identificador: se utiliza cuando queremos aplicar un estilo a un solo elemento HTML. A diferencia de las clases, que se pueden utilizar con varios elementos, el identificador debe ser único. En el elemento HTML se indica el atributo id y en la regla se antepone la almohadilla (#).
  • Descendente: selecciona elementos incluidos en otros elementos. Los elementos se indican separados por un espacio en blanco.
  • Agrupación de selectores: permite indicar un estilo a la lista de selectores. Se separan por comas (,).
  • Hijo: selecciona un elemento que es hijo directo de la etiqueta padre. Se indica con el signo «mayor que» (>).
  • Adyacente: selecciona elementos hermanos cuando uno se encuentra justo al lado de otro. Se indica con el signo más (+).
  • Atributos: permite seleccionar elementos HTML en función de los atributos que tengan asignados. [nombre_atributo] selecciona los elementos que tienen ese atributo, independientemente de su valor; [nombre_atributo=valor] selecciona los que tienen ese atributo con ese valor.

4.1. Ejemplo del uso de selectores

El siguiente documento HTML contiene elementos a los que se aplicarán distintos selectores:

<body>
    <p>P1: El selector universal pone todos los elementos en azul</p>
    <p>P2: Los elementos p están centrados</p>
    <p class="miclase">P3: Este párrafo es de la clase miclase</p>
    <p id="miidentificador">P4: Este párrafo tiene un identificador</p>
    <ul>
        <li>opción1</li>
        <li>opción2</li>
    </ul>
    <h1>Ejemplos de selectores</h1>
    <h2>Diferentes tipos de selectores</h2>
    <p>
        <a>Un enlace</a>
        <span><a>Otro enlace</a></span>
    </p>
    <div>div adyacente al párrafo anterior</div>
    <p lang="es">P5: Este párrafo está escrito en español</p>
    <p lang="en">P6: This paragraph is written in English.</p>
</body>

El siguiente CSS externo se aplica al código:

* { color: blue; }
p { text-align: center; }
.miclase { border: solid 1px red; }
#miidentificador { background-color: cyan; }
ul li { background-color: gray; }
h1, h2 { border: solid 3px green; }
p > a { background-color: yellow; }
p + div { border: solid 2px blue; }
p[lang="es"] { background-color: red; }
p[lang="en"] { background-color: orange; }

Código 3. Ejemplo de uso de selectores y Código 4. Fichero externo estilos_selectores.css.

4.1.1. Explicación del ejemplo

  • * { color: blue; }: todos los elementos tendrán el color azul.
  • p { text-align: center; }: todos los párrafos están alineados al centro.
  • .miclase { border: solid 1px red; }: se aplica un borde rojo de 1 px al párrafo de la clase miclase.
  • #miidentificador { background-color: cyan; }: se aplica fondo cian al elemento con ese identificador.
  • ul li { background-color: gray; }: se aplica fondo gris a los elementos li descendientes de ul.
  • h1, h2 { border: solid 3px green; }: se aplica un borde verde a h1 y h2.
  • p > a { background-color: yellow; }: selecciona los enlaces que son hijos directos de p. El primer enlace sí lo es; el segundo no, porque entre ambos está span.
  • p + div { border: solid 2px blue; }: aplica un borde azul al div que es hermano adyacente de un párrafo.
  • p[lang="es"] y p[lang="en"]: aplican fondos distintos según el valor del atributo lang.
5

Herencia

Uno de los aspectos que debemos considerar en CSS es que los estilos se heredan. Esto implica que, si un elemento HTML se encuentra dentro de otro, el elemento hijo hereda los estilos que se hayan podido definir para la etiqueta padre. Por eso a las hojas de estilo se les suele llamar «hojas de estilo en cascada».

Si para la etiqueta hija se define un estilo que modifica el del padre, se aplicará el estilo de la etiqueta hija.

Por herencia, los dos párrafos deberían tener el color azul, puesto que heredan el estilo del <div>. Sin embargo, al segundo párrafo le indicamos otro estilo y por eso se muestra en rojo.

<style>
    div { color: blue; }
    #p2 { color: red; }
</style>
<div>Este div es el padre
    <p>Un párrafo hijo</p>
    <p id="p2">Otro párrafo hijo</p>
</div>

5.1. Colisiones de los estilos

Si tenemos muchas reglas CSS en un fichero de estilos, puede suceder que se intenten aplicar estilos diferentes a un mismo elemento HTML. En este caso, el mecanismo para determinar el estilo que se debe aplicar depende de aspectos como la especificidad del selector, la importancia de la regla y el orden de las declaraciones.

Como norma general:

  • Cuanto más concreto sea un selector, mayor importancia tendrá y, por lo tanto, será el que se aplique.
  • Si la especificidad y la importancia son iguales, se aplicará la última regla creada.

Por ejemplo, si tenemos las siguientes reglas:

div { color: red; }
div#destacado { color: black; }
* { color: yellow; }

El texto incluido en div#destacado se mostraría de color negro, puesto que ese selector es más concreto. El selector universal (*) tiene menor especificidad y pierde frente a los otros selectores.

Si activamos el inspector de la página en un navegador como Mozilla, que se activa con F12, podremos ver los estilos que se aplican. Al colocarnos sobre <div>, aparecen a la derecha los estilos activos y el navegador tacha el resto.

6

Unidades de medida

Muchas de las propiedades que podemos aplicar a los elementos seleccionados en las reglas CSS se basan en medidas. Por ejemplo, estas se pueden usar para indicar la altura de un elemento, el tamaño de la letra o la anchura de un <div>. Por este motivo, es muy importante conocer qué tipos de medidas existen y sus características. Las unidades se pueden dividir en absolutas y relativas.

6.1. Unidades de medida absolutas

Cuando se trabaja con unidades absolutas, su valor se define de manera completa y no depende de otras referencias. Las unidades absolutas más importantes son:

6.2. Unidades de medida relativas

Este tipo de unidades depende de otro valor de referencia. Las unidades relativas más utilizadas son:

Tabla 2. Unidades relativas
SiglaSignificado
emSe relaciona con el tamaño de la fuente del contenedor padre al que pertenece.
remSe relaciona con el tamaño de la fuente raíz, que suele ser 16 px si no se indica lo contrario.
%Relativo al elemento padre.
vw1 % del ancho de la ventana.
vh1 % del alto de la ventana.

Debemos tener cuidado con el uso de la unidad relativa em, porque al estar relacionada con el contenedor, si tenemos varios contenedores anidados y utilizamos esta unidad en todos, el aumento o disminución del tamaño estaría encadenado.

Cuando se trabaja con móviles, se usan las medidas vw y vh para adaptar el contenido al ancho y alto de la pantalla. Las unidades que más utilizaremos serán px, rem y %.

6.3. Ejemplo de unidades absolutas y relativas

A continuación, se muestra un ejemplo de código con el uso de unidades absolutas y relativas para el tamaño de la fuente:

<style>
    div {
        font-size: 12px;
        border: solid 2px red;
        width: 400px;
        height: 250px;
    }
    #p1 { font-size: 1.5em; }
    #p2 { font-size: 2rem; }
    #p3 { font-size: 175%; }
</style>
<div>
    Esto es un div (12px)
    <p id="p1">Primer párrafo (1.5 × 12px = 18px)</p>
    <p id="p2">Segundo párrafo (2 × 16px = 32px)</p>
    <p id="p3">Tercer párrafo (175 % de 12px = 21px)</p>
</div>

Al <div> se le ha aplicado un borde rojo y un tamaño de fuente de 12 px. También se le ha indicado un ancho y un alto con valores absolutos en px. En cambio, para los párrafos incluidos en el propio <div>, que es su contenedor padre, se han indicado los siguientes valores:

  • Párrafo 1: tamaño de fuente relativo a su padre, porque se usa em.
  • Párrafo 2: tamaño de fuente relativo a la fuente raíz, porque se usa rem. 16 px es el tamaño por defecto indicado en el ejemplo.
  • Párrafo 3: tamaño de fuente relativo a la fuente de <div>: un 175 % de 12 px, que es 21 px.
7

Colores

Una de las primeras cosas que pensamos cuando queremos darle estilo a una página web es cambiarle el color. Para indicar el color que queremos aplicar a un elemento HTML se puede usar:

  • Su nombre: existen nombres predefinidos asociados con los colores. Por ejemplo, red, green y blue. Existe un total de 140 nombres de colores.
  • El valor RGB: estas siglas corresponden a los colores primarios rojo (red), verde (green) y azul (blue). Cada color primario puede tener una intensidad entre 0 y 255. Así, rgb(0, 0, 0) es negro, rgb(255, 255, 255) es blanco y rgb(255, 0, 0) es rojo puro.
  • El valor hexadecimal: es la representación en hexadecimal de la codificación RGB. El valor FF corresponde con 255 y 00 con 0. Por lo tanto, el color rojo en formato hexadecimal sería #FF0000.

Una tabla completa de los colores que se pueden utilizar, indicando su nombre, valor RGB y valor hexadecimal, puede consultarse en los recursos de referencia. Existe una herramienta muy útil que nos permite elegir los colores más adecuados para nuestra página web: Adobe Color CC. Facilita el estudio de los colores análogos, complementarios, compuestos o tonos similares. Hay que tener en cuenta que debe haber un equilibrio entre los colores elegidos en el sitio web para conseguir que visualmente sea atractivo.

10

Resumen y resolución del caso práctico de la unidad

En este tema hemos realizado una introducción a la hoja de estilos CSS indicando sus características y su sintaxis. Es muy importante conocer el uso de los selectores, porque permiten acceder de manera muy concreta a los elementos HTML a los que queremos aplicarles estilos.

Gracias a la herencia no es necesario reescribir reglas que se aplican al contenedor padre, pero hay que tener cuidado con los conflictos entre estilos.

Las unidades de medida nos permiten controlar el tamaño y la disposición en el diseño web, y los colores, el aspecto visual.
