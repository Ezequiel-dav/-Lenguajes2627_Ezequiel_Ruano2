¿Qué es CSS?

CSS es el lenguaje que define la presentación de los documentos HTML. Permite cambiar colores, tamaños, bordes y distribución.

Conectar una hoja de estilos

La forma habitual es guardar las reglas en un archivo externo y enlazarlo desde el elemento head.

<link rel="stylesheet" href="estilos.css">

Reglas CSS

Una regla contiene un selector y una o varias declaraciones de propiedad y valor.

p {
    color: darkgreen;
    font-size: 18px;
}

En este ejemplo, p es el selector. color y font-size son propiedades.
