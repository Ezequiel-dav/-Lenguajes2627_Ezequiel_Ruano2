Propiedad Overflow

Explicación: La propiedad overflow gestiona qué ocurre cuando el contenido de un elemento supera las dimensiones fijas (ancho o alto) asignadas a su contenedor.

Demostración Visual

visible

Este texto es demasiado largo para esta pequeña caja de ejemplo. Como puedes ver, se sale de los bordes.

hidden

Este texto es demasiado largo para esta pequeña caja de ejemplo. Como puedes ver, se corta el contenido sobrante.

scroll

Este texto es demasiado largo para esta pequeña caja de ejemplo. Permite deslizar usando las barras.

auto

Este texto es demasiado largo para esta pequeña caja de ejemplo. Añade la barra solo si hace falta.
